# Credits

Many people from CEA LIST, permanent staff, PhD students and interns, have
contributed to LIMA over the years. The list of authors is maintained in the
[`AUTHORS`](https://github.com/aymara/lima/blob/master/AUTHORS) file.

LIMA builds on several free software libraries and linguistic resources,
including:

- [Qt](https://www.qt.io/) and [Boost](https://www.boost.org/);
- [libtorch](https://pytorch.org/) (PyTorch C++) and
  [Eigen](https://eigen.tuxfamily.org/) for the neural modules;
- [fastText](https://fasttext.cc/) word embeddings;
- [Universal Dependencies](https://universaldependencies.org/) treebanks for
  training the models;
- [NLTK](https://www.nltk.org/) data (Penn treebank extract) for the legacy
  English tagger;
- [SVMTool](https://www.cs.upc.edu/~nlp/SVMTool/) (through its C++ port).

See the [`COPYING`](https://github.com/aymara/lima/blob/master/COPYING) file for
the complete list and their licenses.
